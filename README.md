# Feedback Collector

A simple full-stack web application for collecting, displaying, and managing user feedback.  
Built with a Node.js/Express backend and a vanilla JavaScript frontend.

---

## 🚀 Features
- Submit feedback with name and message
- View all feedback entries
- Delete feedback dynamically
- Lightweight and easy to set up

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express
- **Database:**  MongoDB
- **Version Control:** Git & GitHub
